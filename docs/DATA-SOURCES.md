# DATA-SOURCES.md — Dodgers Injury Tracker

## Primary Data Source: MLB Stats API

### Overview
- URL: https://statsapi.mlb.com/api/
- Cost: Free, no API key required
- Docs: https://github.com/toddrob99/MLB-StatsAPI (community docs)

## Key Endpoints

### Injured List / Roster Status
What the code actually uses (api/injuries.ts): the full roster, then filtered to IL players client-side.
GET https://statsapi.mlb.com/api/v1/teams/{teamId}/roster?rosterType=fullRoster&season={year}
Filter to entries whose status.code is one of D10, D15, D60, ILF and that have a non-empty `note`.

### Season Schedule / Game Log (win% trend)
Used by api/season.ts to build the cumulative win% trend, one entry per completed game.
GET https://statsapi.mlb.com/api/v1/schedule?sportId=1&teamId={teamId}&season={year}&gameType=R&startDate={YYYY-MM-DD}&endDate={YYYY-MM-DD}
IMPORTANT: sportId=1 is REQUIRED — without it the schedule endpoint returns empty results. Scores are read from teams.home.score / teams.away.score on games where status.abstractGameState === "Final".

### Team ID Reference
- Los Angeles Dodgers: 119
- Los Angeles Angels: 108
- San Francisco Giants: 137
- San Diego Padres: 135
- Arizona Diamondbacks: 109

Full team list:
GET https://statsapi.mlb.com/api/v1/teams?sportId=1

### Player Details
GET https://statsapi.mlb.com/api/v1/people/{playerId}

## Response Notes
- IL roster entries include: person.fullName, position, status.code, and a free-text `note` (used as the injury description). The roster endpoint does NOT reliably return the actual IL placement date — api/injuries.ts currently stamps today's date as a placeholder (known issue).
- Actual roster status codes returned by the API: D10 (10-day IL), D15 (15-day IL), D60 (60-day IL), ILF (full-season IL). expectedReturn / impact / notes are generated by Claude, not the MLB API.
- Data is generally current within 24 hours
